* status: wont-fix — superseded by three-tier task structure
* legacy-id: TODO-048
* archived: 2026-05-22

## Original summary

Create a clear separation between the active TODO zone (tasks ready to be picked up) and a sketching zone (loose ideas not yet formalized enough to be acted on).

## Why archived

The three-tier task structure (small/medium/large) implemented in 2026-05-22 provides the equivalent separation through a different mechanism: `documentation/tasks/open_additional_input.md` serves as the human-writable notepad for unstructured input (the sketching zone), and `documentation/tasks/00_index.md` is the active tracker. The entry criteria this task proposed to document are now covered by `documentation/task-principles.md` §8 (Intake from open_additional_input.md).
