# Tasks

This folder is the task tracker for the speaker-mining repository.

**Start here: [00_index.md](00_index.md)** — the single entry point listing all open tasks.

See [task-principles.md](../task-principles.md) for size definitions, naming rules, and the archiving process.

## Structure

- **`00_index.md`** — the full list of open tasks; start here to find work or add a new item
- **`open_additional_input.md`** — drop ideas, observations, or rough notes here if you're not ready to write a full task; someone will turn them into proper task entries
- **`2026-MM-DD_<task_name>.md`** — a dedicated file for each medium-sized task with its motivation, scope, and definition of done
- **`2026-MM-DD_<task_name>/`** — a dedicated folder for larger tasks that need design documents, progress logs, or sub-tasks
- **`archive/`** — tasks that are finished or no longer relevant
